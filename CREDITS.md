# Credits

ZooTogether is built on **[openzt](https://github.com/openzt1/openzt)**, the open-source Zoo Tycoon
(2001) framework. Its DLL loading, detour framework, address tables, Rust ports of the game's managers
and Lua console are the base this co-op mod stands on. Thank you to its contributors:

| Contributor | GitHub | openzt commits (2026-10-30) |
|---|---|---|
| Finn Hartshorn | [finnhartshorn](https://github.com/finnhartshorn) | 111 |
| Eric Galvan | [GoosiferIO](https://github.com/GoosiferIO) | 33 |

(Dependency-update bot commits not counted.) The list comes from openzt's GitHub contributors page;
see it for the current list.

ZooTogether's own changes to openzt live in `patches/openzt-zoo-together.patch` and are released under
the same terms as this repo (GPL-3.0, see [LICENSE](LICENSE)).
